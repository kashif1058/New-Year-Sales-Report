Project Title:
Customer Purchase Behavior Analysis – New Year Sales Data
Objective:
The primary objective of this project is to analyze customer purchase behavior during the New Year sale period using real-world sales data. 
By performing Exploratory Data Analysis (EDA), we aim to extract actionable insights related to customer demographics, product trends, 
and regional sales performance that can help improve business strategies.
Dataset Overview:
File: New Year Sales Data.csv

Rows: 11,251

Columns: 15 (after cleaning: 13)

Key Features:

User_ID, Cust_name, Gender, Age, Marital_Status

State, Zone, Occupation

Product_ID, Product_Category

Orders, Amount
Tools & Libraries Used:
Python

Pandas – Data manipulation

NumPy – Numerical computations

Matplotlib & Seaborn – Data visualization
